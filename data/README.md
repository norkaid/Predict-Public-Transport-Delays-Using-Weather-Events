# Data

Download the Kaggle dataset
[Public Transport Delays with Weather and Events](https://www.kaggle.com/datasets/khushikyad001/public-transport-delays-with-weather-and-events)
and place `public_transport_delays.csv` in this folder.

```bash
kaggle datasets download -d khushikyad001/public-transport-delays-with-weather-and-events -p data --unzip
```

CSV files in this folder are git-ignored.
